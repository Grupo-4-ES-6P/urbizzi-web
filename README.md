# Urbizzi Web

Scaffold técnico do frontend web da Urbizzi.

## Base configurada

- React 18 e React DOM
- TypeScript
- Vite
- React Router
- Lucide Icons
- ESLint
- Vitest e Testing Library
- Fontsource

## Instalação

```bash
npm install
```

O código da aplicação, incluindo a pasta `src` e o arquivo `index.html`, ainda não foi criado intencionalmente.
